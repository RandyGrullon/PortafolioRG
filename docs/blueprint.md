# **App Name**: Freelance Foundry

## Core Features:

- Hero Section: A landing section with split screen design; image on the left, key selling points with call to action (WhatsApp link) on the right.
- Content Sections: Sections dedicated to 'Projects', 'About', and 'Contact' information.
- WhatsApp Button: A WhatsApp button with text 'Happy to chat on WhatsApp', opening a new tab with a link to a WhatsApp chat.
- Image Display: Display a grayscale image of the developer on the left side of the screen, with a blue soft-light overlay.
- Responsive Layout: A responsive design that adapts to different screen sizes, changing the layout from a two-column to a vertical arrangement on mobile devices.
- Subtle Animations: Fade-in effects when loading text and images for a smooth user experience.

## Style Guidelines:

- Primary color: Dark background (#0D0A0B) for a modern, agency-like feel.
- Secondary color: Magnolia (#F3EFF5) for titles, ensuring readability against the dark background.
- Accent color: Azure (#0084FF) for interactive elements and highlights, providing a vibrant contrast.
- Font: 'Space Grotesk' (sans-serif) for a modern, tech-forward aesthetic suitable for both headlines and body text.
- Large titles in Magnolia (#F3EFF5) and subtitles/text in Charcoal (#454955) with 0.8 opacity for a clean look.
- Split-screen layout with image on the left and text on the right (desktop), converting to a vertical layout on mobile devices.
- Maintain generous margins and high contrast for excellent legibility and readability.
- Subtle fade-in effects when loading text and images to enhance the user experience.
- Use a green WhatsApp icon for the chat button with a smooth hover effect (transform: scale(1.05); box-shadow:leve).
